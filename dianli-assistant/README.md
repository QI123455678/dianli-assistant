# 电力行业工作助手 - 安装部署指南

这是一个专为手机使用设计的网页应用（PWA），包含三个功能：

1. 📰 **每日电力新闻简报**（自动抓取国家能源局官方新闻，附原文链接）
2. 📊 **工作台账**（记录你的工作，数据保存在手机本地，电脑关机也能用）
3. 🤖 **AI 辅助**（分享给手机自带 AI，或内置 AI 对话）

---

## 一、你需要准备什么

- 一个 **GitHub 账号**（免费，只需要这一个账号）
- 一台能上网的电脑（只在部署时用一次，之后不需要）

> 推荐用下面的「方案 A：GitHub Pages」，只需注册 GitHub 一个账号即可，最简单。

---

## 二、部署步骤（跟着做就行）

### 第 1 步：注册 GitHub

1. 打开网址：https://github.com
2. 点右上角 **Sign up**（注册）
3. 填邮箱、密码、用户名，一路下一步，完成邮箱验证

### 第 2 步：创建仓库，上传这些文件

1. 登录 GitHub 后，点右上角 **+** → **New repository**
2. 仓库名填：`dianli-assistant`（随便起也行）
3. 选 **Public**（公开），点 **Create repository**
4. 上传文件（关键一步，仔细看）：
   - 在新建好的仓库页面，找到 **uploading an existing file**（蓝色链接，一般在页面中间）
   - 打开你电脑上的 `dianli-assistant` 文件夹
   - **把整个文件夹里所有东西一起拖拽到网页上的虚线框里**（包括 `api`、`css`、`js`、`icons`、`scripts`、`.github` 这些子文件夹，以及 `index.html` 等文件，全部一起拖）
   - 拖进去后，等文件列表出现，往下滑点绿色的 **Commit changes** 按钮

> 💡 提示：如果拖拽没反应，可以点虚线框里的「choose your files」，在弹窗里按 Ctrl+A 全选文件夹里的所有文件和子文件夹，一起选。

### 第 3 步（方案 A，推荐）：开启 GitHub Pages

1. 进入你的仓库页面，点顶部 **Settings**（设置）
2. 左侧找到 **Pages**（页面）
3. 在 **Branch** 下拉框里选 **main**，保存
4. 等 1~2 分钟，页面上会出现一个网址，形如：
   `https://你的用户名.github.io/dianli-assistant/`

> GitHub 每天会自动抓取更新新闻（通过 GitHub Actions），你也可以在仓库的 **Actions** 页面点 **Run workflow** 手动立即更新一次。

### 第 3 步（方案 B，备选）：用 Vercel 部署

> 如果方案 A 的网址打不开新闻，或想要「打开即最新新闻」的实时效果，用这个方案。

1. 打开网址：https://vercel.com
2. 点 **Sign up**，选择 **Continue with GitHub**（用 GitHub 登录）
3. 登录后，点 **Add New...** → **Project**
4. 在列表里找到你刚创建的 `dianli-assistant` 仓库，点 **Import**
5. 直接点 **Deploy**（部署），其他设置都不用改
6. 等 1~2 分钟，出现 🎉 表示部署成功，会给你一个网址，形如：
   `https://dianli-assistant-xxxx.vercel.app`

### 第 4 步：装到手机上

1. 用手机浏览器（微信扫码、或直接输入网址）打开上面那个网址
2. 安卓手机浏览器菜单里找 **「添加到主屏幕」** 或 **「安装应用」**
   - Chrome/Edge 浏览器：点右上角 ⋮ → 「安装应用」或「添加到主屏幕」
   - vivo 自带浏览器：点菜单 → 「添加至桌面」
3. 桌面上就会出现「电力助手」的图标，点开就能用

## 三、使用说明

### 📰 新闻简报
- 打开后自动抓取，或点「🔄 刷新简报」手动更新
- 点任意新闻可打开原文链接
- 「📤 分享简报」可把简报复制或分享出去

### 📊 工作台账
- 点「＋ 记一笔」手动添加记录（日期、标题、内容、分类）
- 点「📥 导入日报」把日报粘贴进来，或上传文件（支持 .txt / Word .docx / Excel .xlsx），软件自动按日期拆分成多条台账
- 支持搜索、按月筛选
- 点已有记录可编辑或删除
- 「⬇ 导出备份」把台账导出成 JSON 文件保存
- 「⬆ 恢复备份」把之前导出的备份导入回来（换手机时用），可选「追加合并」或「覆盖恢复」

### 🤖 AI 辅助
- **分享给蓝心小V**：把内容粘贴到文本框，点「分享给蓝心小V」，在弹出菜单里选手机 AI
- **内置 AI**：需要先填一个 AI 接口密钥（可选）
  - 到 https://platform.deepseek.com 注册（免费），创建 API Key
  - 把 Key 粘贴到「AI 接口密钥」栏，点保存，即可直接对话

## 四、常见问题

**Q：换手机了，台账数据会丢吗？**
A：台账存在手机本地。换手机前请先用「⬇ 导出备份」保存到文件，再在新手机上用「⬆ 恢复备份」导入即可。

**Q：电脑关机了还能用吗？**
A：能！台账和 AI 分享功能完全在手机本地。只有新闻简报需要联网（用手机网络即可，不依赖电脑）。

**Q：新闻抓取失败？**
A：检查手机网络。新闻来自国家能源局官网，偶尔网络波动会失败，稍后重试即可。

**Q：方案 A（GitHub Pages）的新闻多久更新一次？**
A：GitHub 每天自动抓取更新两次（早 7 点、晚 7 点）。也可以在仓库的 **Actions** 页面点 **Run workflow** 手动立即更新。

## 五、开发者信息

- 新闻数据源：国家能源局官网（nea.gov.cn）公开数据接口
- 技术栈：原生 HTML/CSS/JS + PWA + IndexedDB
- 部署方式：
  - 方案 A：GitHub Pages（静态托管）+ GitHub Actions 定时抓取新闻
  - 方案 B：Vercel（Serverless Functions 实时抓取）
- 前端同时支持两种方式，自动优先尝试实时接口、失败回退静态文件
